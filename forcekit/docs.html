Guide

Features, shortcuts and icons, all in one place.

A quick tour of everything ForceKIT can do — from the SOQL console to data import, debug logs, user search and comparisons — plus what every icon in the panel means.

SOQL Console

SOQL Autocomplete

Suggests fields after SELECT/WHERE and objects after FROM (STD/TOOLING tags).

Shortcuts

Ctrl+Space inserts all fields (or only the ones matching what you've typed), Ctrl+Shift+Space opens suggestions.

Run query

Ctrl+Enter runs the query immediately (or cancels it, if one is already running).

Undo/Redo

Ctrl+Z undoes the last edit, Ctrl+Shift+Z (or Ctrl+Y) redoes it.

Navigation

↑/↓ to select, Enter/Tab to insert, Esc to close.

Smart editing

Keywords auto-capitalize, LIKE + space inserts '%%' with the cursor centered.

Query cleanup

Automatically removes duplicate fields and double commas.

SOQL formatting

Reorders clauses and fixes misplaced commas.

Details

Captures the link from the active tab.

SELECT *

Inserts all fields (*c custom only, *s standard only) without the FIELDS(ALL) 200-record limit.

Column filter

In the results search box, type ColumnName: text to search only that column, ColumnName: null for empty values, ColumnName: !null for non-empty ones.

Filter by type

In Details, the funnel icon next to the search filters the table by field type (String, Picklist, Number, etc.).

REST vs. Tooling API

ForceKIT detects when an object is Tooling-only and runs the query there automatically — a small badge next to the results shows which API was used.

SOSL search

Type a FIND {...} IN ... RETURNING query instead of SELECT to search across multiple objects at once, right in the same console.

Results & records

✏️

Inline editing of results

Turn on edit mode in the results table and double-click a cell to change it: picklists become dropdowns, checkboxes toggle, long text opens a text area. Every change is highlighted and all of them are saved together in one click, with a clear list of any errors. Formula, relationship and read-only columns are greyed out and can be hidden.

📤

Export your records

Copy the results as CSV, Excel or JSON, or download them as a file, ready to paste into a spreadsheet or another tool.

↕️

Sort and choose columns

Click a header to sort ascending or descending. From the columns menu you can hide or show each column, hide all empty columns at once and restore everything whenever you want.

🧩

Subqueries and SELECT *

Parent-child results show the nested records, which you can expand or search. SELECT *, *c and *s also work inside subqueries, e.g. SELECT Id, (SELECT *c FROM Contacts) FROM Account.

🙋

Your User Id, suggested

After CreatedById =, LastModifiedById = or OwnerId = the autocomplete proposes your own User Id, so "my records" queries take a second.

🗂️

Query tabs and history

Keep several queries open in parallel tabs. Every query you run lands in History, where you can search it, save it with a name, and import or export your favourites.

🔎

Details: the whole record

Open any record from the active tab, an Id or a link and see every field with its label, API name, type and value. Edit, refresh or delete it, filter fields by type and hide the empty ones with one click.

🔗

Related records at a glance

Details also lists the child relationships with the number of related records, and turns lookups into links: jump to a parent or related record without leaving the panel.

🎯

Capture from list views

Hover a row in any Salesforce list view and a small ForceKIT icon appears: open that record in Details, or mark it as record A or B and compare it straight away — no Ids to copy.

Data import

📥

Insert, update, upsert, delete

Paste rows from Excel or a CSV, pick the object and the operation (upsert by External Id, with optional assignment rules). Works through REST, Tooling or Metadata, so you can load metadata records too.

🧹

Checks before you run

ForceKIT flags the columns that can't be written (formula, not createable or updateable fields) and removes them in one click; a confirmation summary shows how many records and fields will be sent.

⏯️

Live progress, stop anytime

Set batch size and parallel threads, watch queued, processing, succeeded and failed records update live, and stop the job safely at any moment.

🩺

Errors you can understand

Every failure is listed with the Salesforce error and a plain-language hint on how to fix it. Filter by outcome, copy the results to Excel/CSV and retry only the failed rows.

Debug logs

🎚️

Debug levels and trace flags

Turn on logging for any user (or yourself) with ready-made level presets, see who is being debugged right now, and renew or stop trace flags in one click.

🧮

Filter the log list

Filter logs by user and by text (operation, status, …), choose the page size and move through the pages; delete all the filtered logs at once when you're done.

📂

Import a log file

Drag and drop a .log or .txt file (or pick it) — even one exported from another org or sent by a colleague — and analyse it with all the same tools. Large logs open in their own window.

🌳

Order of Execution tree

A navigable tree of code units, triggers, flows and methods, color-coded by kind. Expand or collapse it level by level with − / +, and copy or download it as an indented text tree.

📊

Queries, DML, debug and limits

Ready-made tables for SOQL/SOSL (numbered, with the class that runs them, rows and duration), DML, User Debug and Governor limits — each copyable or downloadable as CSV. One click jumps to the exact line in the raw log.

🎨

Color-coded raw log

The raw log is colored by category (execution flow, database, errors, limits…); click the legend to show only the categories you care about, and search inside the log.

🗃️

Several logs side by side

Open up to 8 logs in tabs and switch between them instantly; widen the detail view to read long lines comfortably.

Users and compare

👥

User search

Find users by first and/or last name, username, email or Id, filter by profile and choose which columns to show. Open the user's details or Login As in one click.

⚖️

Compare profiles and permission sets

Pick two profiles or permission sets and see object and field permissions side by side, with the differences highlighted and the identical rows hidden if you like.

🆚

Compare two records

Paste two Ids or links — or capture them from a list view or a record page — and see every field side by side with the differences highlighted.

Sessions and security

🌐

Every open org, one click away

The orgs you are logged into are detected automatically: switch between them in one click, pin your favourites, give each one a color and copy a link that reopens the current org.

🔐

Credentials, TOTP and passkey

Save logins and two-factor codes encrypted with a master password, unlock them with a passkey (fingerprint, face or PIN) and decide when they lock again.

☁️

Sync and backup

Optionally sync your settings, history and credentials through your Chrome account, or back them up to your own Google Drive. Off by default.

🖥️

Side panel or full page

Use ForceKIT in Chrome's side panel next to your org, or open it full page in its own tab, with zoom, accent colors and dark mode.
