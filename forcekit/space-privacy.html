Privacy Policy · ForceKIT Space

What ForceKIT Space does with your data.

Last updated: November 10, 2026

Summary

ForceKIT Space is a Chrome extension that works on the code of the Salesforce org you are logged into. It talks only to that org, using the session already open in your browser. It has no server of its own, no analytics and no advertising, and it does not sell or share any data.

Talking to Salesforce

To read and save code, run tests and read logs, ForceKIT Space reads the Salesforce session cookie (sid) of the org you open it from, only on Salesforce domains, and uses it to call that org's REST, Tooling and Metadata APIs. The session is never stored, logged or sent anywhere else. Code, logs, test results and deployments are shown in the page and not saved.

What's stored in your browser

Your preferences (language, theme, editor text size and word wrap, whether panels are open), your test run sets (named groups of test classes), the last test run of each org and which Space tab is open for each org. Nothing of this leaves your browser unless you turn sync on.

Sync (optional, off by default)

In Settings › Sync you can copy preferences and run sets to your Chrome account (chrome.storage.sync) or to a file in the hidden App Data folder of your own Google Drive (scope drive.appdata, through chrome.identity). No other Google data is read. Sessions and code are never synced. Disconnecting Google Drive revokes the token.

Working together with ForceKIT

Other extensions can only ask ForceKIT Space whether it is installed (it answers with its version) and ask it to open on a Salesforce address. ForceKIT uses this for its { } button. No session, code or data passes between the two extensions.

Permissions, plainly explained

  • cookies: to read the Salesforce session of the org you are working on, and to list the orgs you are logged into.
  • storage: to keep your preferences, run sets and the last test run of each org.
  • identity: only if you choose Google Drive as sync, to save your preferences in your own Drive.
  • Access to Salesforce domains (salesforce.com, force.com, salesforce-setup.com, cloudforce.com, visualforce.com): the domains where orgs live, to call their APIs. No other website is accessed and no script is injected into any page.

What we don't do

No server of ours, no analytics or tracking, no ads, no remote code: everything, including the Monaco editor, is inside the extension. We don't sell or transfer data, and don't use it for anything other than the editor itself.

Deleting your data

Removing the extension from Chrome deletes everything it stored in the browser. A synced copy is removed by turning sync off in Settings and, for Google Drive, from Drive's “Manage apps” page.
