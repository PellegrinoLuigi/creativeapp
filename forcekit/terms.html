The service

ForceKIT is a Chrome extension that adds productivity tools on top of Salesforce: a SOQL console, inline API names, a Profile/Permission Set comparator, cache refresh, dark mode, Lightning/Classic switching, saved-session management, and optional sync across your own devices. It runs entirely inside your browser and has no server of its own — see the Privacy Policy for the full detail on what's stored and where.
